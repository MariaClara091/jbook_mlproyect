# Bienvenido a nuestro Miniproyecto
# Autores: María Clara Ávila Chinchia, David Alejandro Ibáñez Barrios y Mateo José Giraldo Castillo

En este proyecto vamos a indagar acerca de las condiciones socioeconómicas y hábitos de estudio para entrenar un modelo predictivo que anticipe este riesgo mediante la base de datos proporcionada sobre rendimiento académico, con el objetico de facilitar intervenciones más efectivas dichos casos.
